## 🏛️ 4 Exact Walls Overview (NovaLink Modern Executive Suite)

1. **Wall 1: NovaLink Investigation Board & Product Time Machine** (`assets/wall1_novalink.jpg`)
   - **Entrance Door**: Main glass/wood entrance door (locked from outside).
   - **Product Time Machine / Wall Clock**: Interactive clock riddle (set hands to `4:00` to reveal **Knowledge Box 03** & Painting Piece 3).
   - **Investigation Board**: Central corkboard with red thread, photos, and evidence files.

2. **Wall 2: Executive Desk & Notice/Pin Board** (`assets/wall2_novalink.jpg`)
   - **Notice Board**: Displays the crucial clue pinboard and sticky notes.
   - **Mystery Frame**: Interactive desk scratch mini-game on executive desk (drag mouse/touch to reveal passcode `29`).
   - **Drawer 01 Keypad**: Enter passcode `29` to unlock executive drawer, revealing **Knowledge Box 01** & Painting Piece 1.

3. **Wall 3: Emergency Exit Door & Whiteboard Canvas** (`assets/wall3_novalink.jpg`)
   - **Flower Canvas / Whiteboard (0/3 Pieces)**: Place all 3 restored painting pieces to unlock the **Golden Escape Key**!
   - **Emergency Exit Door**: Use the Golden Escape Key to unlock the exit door, complete Room 1, and unlock Specialized Chambers (Rooms 2–5).

4. **Wall 4: Design Thinking Station & Bookshelf** (`assets/wall4_novalink.jpg`)
   - **Glowing Secret Red Book**: Click the crimson book on the right bookshelf unit to trigger the bookshelf mechanism, open the Steel Wall Safe, and reveal **Knowledge Box 02** & Painting Piece 2.
   - **Design Thinking Station**: Whiteboard with interactive sticky note clues.

## 🚀 How to Open and Run in VS Code

### Step 1: Open Folder in VS Code
1. Open **VS Code**.
2. Click **File** > **Open Folder...**
3. Select this directory:
   ```
   C:\Users\hp\.gemini\antigravity\scratch\escape-room-entrepreneur
   ```

### Step 2: Run the Web App
#### Option A: VS Code Live Server (Recommended)
1. Install the **Live Server** extension (by Ritwick Dey) from the VS Code Extensions tab (`Ctrl+Shift+X`).
2. Right-click on [`index.html`](file:///C:/Users/hp/.gemini/antigravity/scratch/escape-room-entrepreneur/index.html) in the file explorer.
3. Click **"Open with Live Server"**.
4. The escape room game will launch in your browser at `http://127.0.0.1:5500`.

#### Option B: Direct Browser Launch
- Double click [`index.html`](file:///C:/Users/hp/.gemini/antigravity/scratch/escape-room-entrepreneur/index.html) directly in Windows File Explorer or open it in Google Chrome / Edge.

#### Option C: Terminal Serve Command
Open the terminal in VS Code (`Ctrl+` `~`) and run:
```bash
npx -y serve .
```

## 🎮 Controls & Navigation

- **Rotate Left**: Click `[❮ LEFT WALL]` disc, press `←` (Left Arrow), or press `A`.
- **Rotate Right**: Click `[❯ RIGHT WALL]` disc, press `→` (Right Arrow), or press `D`.
- **Direct Wall Jump**: Click any of the 4 indicator dots at the bottom center.
- **Interact / Inspect**: Click any glowing item, door, clock, desk frame, drawer, book, or canvas.
- **Satchel Inventory**: Click the `🎒 SATCHEL` button in the bottom HUD.
- **Mentor Hints**: Click `💡 HINT` to get guidance from Professor Vance.
- **Print Certificate**: Click `📜 CERTIFICATE` to download/print your official deAsra inspireLIFE Certificate.
